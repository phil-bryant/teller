- Mandatory: you must code in an object-oriented way that respects encapsulation


# Your rule content

- you are prohibited from using the syntax: "break"
- you are prohibited from using the syntax: "continue"
- you are prohibited from using the syntax: "pass"
- you are prohibited from putting multiple return statements in the same method
- you are prohibited from using return except as the very last statement in a method
- you are prohibited from using isinstance(...) this looks like a guard clause or a violation of object-oriented principles
- you are prohibited from using hasattr(...) this also looks like a guard clause or a violation of object-oriented principles
